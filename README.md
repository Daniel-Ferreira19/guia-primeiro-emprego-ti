# "Desisto da área de TI": o que ninguém te conta sobre o processo

## Objetivo
Ao final deste guia, o leitor será capaz de identificar se sua forma de estudo e busca por vagas está alinhada com o que o mercado espera de um candidato a estágio/primeiro emprego, reconhecendo possíveis erros na própria estratégia (como falta de direcionamento, portfólio fraco ou aplicação para vagas incompatíveis com seu nível).

## Público-alvo
Estudantes que já possuem conhecimento básico de programação, mas ainda não conseguiram seu primeiro estágio ou emprego na área de TI.

## Pré-requisitos
Conhecimento básico de programação (lógica, alguma linguagem ou fundamentos de desenvolvimento).

## Estrutura do guia
- docs/01-introducao.md
- docs/02-conceitos.md
- docs/03-exercicios.md
- docs/04-referencias.md

## Como navegar
Recomenda-se a leitura sequencial dos módulos, na ordem abaixo:

1. *Introdução* — contextualiza o problema e por que ele é comum entre quem busca o primeiro estágio/emprego.
2. *Conceitos* — apresenta os principais pontos que costumam travar a entrada na área de TI (direcionamento de estudos, portfólio, forma de aplicar para vagas).
3. *Exercícios* — propõe uma autoavaliação prática para o leitor identificar onde está sua própria estratégia.
4. *Referências* — reúne materiais complementares para aprofundamento.

Leitores que já têm clareza sobre sua estratégia de estudo podem ir direto para a seção de Exercícios, mas a leitura completa é recomendada para melhor aproveitamento.
