# Exercícios

Estes exercícios não têm "resposta certa" — o objetivo é te ajudar a fazer uma autoavaliação honesta sobre sua estratégia atual de estudo e busca por vagas.

## Exercício 1 — Direcionamento de estudos

Liste as 3 tecnologias ou temas que você mais estudou nos últimos 3 meses.

Pergunta: você conseguiria explicar, com profundidade, **como** e **por que** usaria cada uma delas em um projeto real? Ou seu conhecimento parou no nível de "já vi, mas nunca apliquei sozinho"?

## Exercício 2 — Portfólio

Acesse seu GitHub (ou onde guarda seus projetos) e responda:

- Quantos projetos você tem que **não** foram copiados de um tutorial sem modificação?
- Algum deles resolve um problema real, ainda que pequeno?
- Se um recrutador abrisse seu perfil agora, o que ele entenderia sobre o que você sabe fazer?

## Exercício 3 — Vagas aplicadas

Pegue as últimas 5 vagas para as quais você se candidatou.

- Quantas pediam tecnologias que você realmente domina?
- Quantas eram vagas de nível pleno/sênior disfarçadas de "júnior"?

## Exercício 4 — Plano de ajuste

Com base nas respostas acima, escreva 3 ações concretas que você pode tomar nas próximas 2 semanas para corrigir o que identificou (ex: finalizar um projeto autoral, revisar o README dos seus repositórios, filtrar melhor as vagas antes de aplicar).
