# Referências

Materiais e práticas que podem ajudar a colocar em prática o que foi discutido neste guia.

## Direcionamento de estudos

- Escolher uma trilha de estudo estruturada e segui-la até o fim antes de trocar de assunto, evitando dispersão entre várias tecnologias ao mesmo tempo.
- Buscar descrições de vagas reais (mesmo sem se candidatar) para entender o que o mercado está pedindo hoje.

## Construção de portfólio

- Documentar cada projeto com um README explicando o problema resolvido, as tecnologias usadas e o motivo das escolhas.
- Priorizar poucos projetos bem explicados a muitos projetos rasos ou copiados de tutorial.

## Busca de vagas

- Ler a descrição completa da vaga antes de aplicar, verificando se o nível (estágio, júnior, pleno) é compatível com sua experiência atual.
- Ajustar o currículo para destacar as tecnologias específicas pedidas em cada vaga.

## Sobre este guia

Este material foi produzido como projeto integrador da trilha de Git/GitHub, unindo prática de versionamento com uma reflexão real sobre o processo de entrada na área de TI. Veja o arquivo `aprendizados.md` para a reflexão final sobre o desenvolvimento deste projeto.
